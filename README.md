# projects_ 
1st PROJECT:  AI Outbound Calling Agent (n8n)

 Overview

An AI-powered outbound calling workflow built with **n8n** and **ElevenLabs**. The workflow collects customer information from a submission form, places an AI voice call that talks just like real humans  and stores the collected data in Google Sheets.

 Features

* Form-based lead collection
* AI outbound voice calls
* Customer requirement gathering
* Automatic Google Sheets logging

 Tech Stack

* n8n
* ElevenLabs
* Google Sheets


2nd PROJECT:  Google Maps Lead Scraper (n8n)

 Overview

An automated lead generation workflow that extracts business information from Google Maps and saves it directly to Google Sheets that contains details like [business name , address , email-id, contact number , business type , rating , review strength ]

 Features

* Business lead scraping
* Keyword & location search
* Automatic data extraction
* Google Sheets integration

 Tech Stack

* n8n
* Google Maps
* Google Sheets
